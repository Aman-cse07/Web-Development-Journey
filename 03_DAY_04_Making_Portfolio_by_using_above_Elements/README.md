# Personal Portfolio Website

## 📖 About the Project

This is a simple Personal Portfolio Website created using HTML5. The project showcases personal information, educational background, technical skills, hobbies, and contact details in a structured and user-friendly format.

The purpose of this project is to practice fundamental HTML concepts such as headings, paragraphs, images, lists, hyperlinks, and text formatting tags.

---

## 🎯 Features

* Display personal introduction.
  
* Add profile image.
  
* Show address information.
  
* Present educational qualifications.
  
* List technical skills and frameworks.
  
* Showcase hobbies and interests.
  
* Provide contact information.
  
* Include LinkedIn profile link.

---

## 🛠 Technologies Used

* HTML5

---

## 📚 HTML Concepts Practiced

### Headings

Used heading tags (`h1`, `h2`) to organize different sections of the portfolio.

### Paragraphs

Used the `<p>` tag to display personal and descriptive information.

### Images

Used the `<img>` tag to display a profile picture.

### Lists

* Unordered Lists (`ul`)
  
* Ordered Lists (`ol`)
  
* List Items (`li`)

### Hyperlinks

Used the Anchor (`a`) tag to connect the LinkedIn profile.

### Text Formatting

* Bold (`b`)
  
* Underline (`u`)
