# HTML Headings and Paragraph Tags

## 📖 Introduction

This repository contains examples and explanations of HTML heading tags (`h1` to `h6`) and the paragraph tag (`p`). These elements are the foundation of web page content structure and help organize information effectively.

## 🎯 Objectives

* Understand the purpose of heading tags in HTML.
  
* Learn the hierarchy of headings from `h1` to `h6`.
  
* Learn how to create paragraphs using the `<p>` tag.
  
* Build a well-structured web page using headings and paragraphs.

## 📌 HTML Heading Tags

HTML provides six levels of headings:

### H1 Tag

```html
<h1>This is Heading 1</h1>
```

* Largest and most important heading.

* Usually used for the main title of a webpage.

### H2 Tag

```html
<h2>This is Heading 2</h2>
```

* Used for major sections of content.

### H3 Tag

```html
<h3>This is Heading 3</h3>
```

* Used for subsections under H2.

### H4 Tag

```html
<h4>This is Heading 4</h4>
```

* Used for smaller subdivisions.

### H5 Tag

```html
<h5>This is Heading 5</h5>
```

* Less important heading level.

### H6 Tag

```html
<h6>This is Heading 6</h6>
```

* Smallest heading tag available in HTML.

## 📌 Paragraph Tag

The paragraph tag is used to display blocks of text.

```html
<p>This is a paragraph in HTML.</p>
```

### Features of Paragraph Tag

* Used to write textual content.
  
* Automatically adds spacing before and after the paragraph.
  
* Improves readability of web pages.

## 💻 Example Program

```html
<!DOCTYPE html>
<html>
<head>
    <title>Headings and Paragraph</title>
</head>
<body>

    <h1>Main Heading</h1>
    <h2>Sub Heading</h2>
    <h3>Section Heading</h3>
    <h4>Small Heading</h4>
    <h5>Smaller Heading</h5>
    <h6>Smallest Heading</h6>

    <p>
        This is a paragraph demonstrating the use of the HTML paragraph tag.
        It is used to display text content on a webpage.
    </p>

</body>
</html>
```

## 🚀 Output

The webpage displays six different heading levels followed by a paragraph of text.
