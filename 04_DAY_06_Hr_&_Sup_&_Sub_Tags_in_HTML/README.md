# HTML HR, Subscript and Superscript Tags

## 📖 Introduction

This project demonstrates the use of the HTML Horizontal Rule (`<hr>`), Subscript (`<sub>`), and Superscript (`<sup>`) tags. These tags help improve the structure and presentation of content on web pages.

---

## 🎯 Objectives

* Learn how to create horizontal lines using the `<hr>` tag.
  
* Understand the use of subscript text with the `<sub>` tag.
  
* Understand the use of superscript text with the `<sup>` tag.
  
* Practice formatting scientific and mathematical expressions in HTML.

---

## 📌 Horizontal Rule Tag (`<hr>`)

The `<hr>` tag is used to create a horizontal line that separates sections of content.

### Syntax

```html
<hr>
```

### Example

```html
<h1>My Portfolio</h1>
<hr>
<p>Welcome to my portfolio website.</p>
```

### Purpose

* Separates content sections.
  
* Improves webpage organization.
  
* Enhances readability.

---

## 📌 Subscript Tag (`<sub>`)

The `<sub>` tag displays text slightly below the normal text line.

### Syntax

```html
Text<sub>Subscript</sub>
```

### Example

```html
H<sub>2</sub>O
```

### Output

H₂O

### Common Uses

* Chemical formulas
  
* Mathematical notations
  
* Scientific expressions

---

## 📌 Superscript Tag (`<sup>`)

The `<sup>` tag displays text slightly above the normal text line.

### Syntax

```html
Text<sup>Superscript</sup>
```

### Example

```html
x<sup>2</sup>
```

### Output

x²

### Common Uses

* Mathematical powers
  
* Exponents
  
* Footnotes and references

## 💻 Complete Example

```html
<!DOCTYPE html>

</html>
```
