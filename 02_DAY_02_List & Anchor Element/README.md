# HTML Lists and Anchor Element

## 📖 Introduction

This repository demonstrates the use of HTML Lists and Anchor Elements. These tags help organize content and create navigation links within web pages and across websites.

## 🎯 Objectives

* Learn about different types of HTML lists.
  
* Understand Ordered Lists and Unordered Lists.
  
* Learn how to create hyperlinks using the Anchor (`<a>`) tag.
  
* Build structured and navigable web pages.

---

## 📌 HTML Lists

Lists are used to group related items together.

### 1️⃣ Unordered List (`<ul>`)

Displays items with bullet points.

**Code:**

```html
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

**Output:**

* HTML
  
* CSS
  
* JavaScript

---

### 2️⃣ Ordered List (`<ol>`)

Displays items with numbers.

**Code:**

```html
<ol>
    <li>Wake Up</li>
    <li>Study HTML</li>
    <li>Practice Coding</li>
</ol>
```

**Output:**

1. Wake Up
2. Study HTML
3. Practice Coding

## 📌 Anchor Element (`<a>`)

The Anchor tag is used to create hyperlinks that connect one page to another.

### Basic Syntax

```html
<a href="https://www.google.com">Visit Google</a>
```

### Example

```html
<a href="https://github.com">Visit GitHub</a>
```

### Common Attributes

| Attribute       | Description                                    |
| --------------- | ---------------------------------------------- |
| href            | Specifies the destination URL                  |
| target="_blank" | Opens the link in a new tab                    |
| title           | Provides additional information about the link |

### Example with Attributes

```html
<a href="https://github.com" target="_blank" title="Open GitHub">
    Visit GitHub
</a>
```
