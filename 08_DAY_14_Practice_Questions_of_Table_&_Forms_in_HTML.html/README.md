# HTML Tables and Forms Project

## 📖 Overview

This project demonstrates the use of advanced HTML tables and form elements. It includes a student information table with merged rows and columns, a user registration form, and a feedback form.

The project helps in understanding how to structure tabular data and collect user input through various HTML form controls.

---

## 🎯 Objectives

* Create structured tables using HTML.
* Use `rowspan` and `colspan` attributes.
* Build interactive forms.
* Collect user information through various input elements.
* Design a feedback form.

# 🔹 Rowspan

The `rowspan` attribute allows a cell to span multiple rows.

### Example

```html id="9zv1lm"
<th rowspan="6">Info</th>
```

### Purpose

* Merges multiple rows into a single cell.
* Improves table organization.

---

# 🔹 Colspan

The `colspan` attribute allows a cell to span multiple columns.

### Example

```html id="9xz0hk"
<th colspan="2">Address</th>
```

### Purpose

* Merges multiple columns into one.
* Creates grouped table headers.

# 🔹 Radio Buttons

Used for selecting a single option.

### Example

```html id="fjlwmh"
<input type="radio" name="gender" value="male">
```

### Features

* Only one option can be selected.
* Suitable for gender and rating selections.

---

# 🔹 Dropdown Menu

The `<select>` element creates a dropdown list.

### Example

```html id="rceh93"
<select name="country">
    <option>India</option>
    <option>Bhutan</option>
</select>
```

### Benefits

* Saves space.
* Provides predefined options.

---

# 🔹 Textarea

Used to collect multiline text input.

### Example

```html id="9fb23s"
<textarea rows="5" cols="25"></textarea>
```

### Use Cases

* Feedback
* Comments
* Suggestions
* Messages

---

# 🔹 Checkbox

Checkboxes allow users to select or confirm options.

### Example

```html id="2uwslv"

<label>Subscribe?</label>
```

### Use Cases

* Terms and Conditions
* Newsletter Subscription
* Multiple Selections
