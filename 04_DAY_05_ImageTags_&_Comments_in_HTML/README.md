# HTML Image Tag and Comments

## 📖 Introduction

This project demonstrates the use of the HTML Image Tag and HTML Comments. These elements are essential for creating visually appealing webpages and writing readable, maintainable code.

---

## 🎯 Objectives

* Learn how to display images on a webpage.
  
* Understand the purpose of HTML comments.
  
* Explore image attributes such as `src`, `alt`, `height`, and `width`.

---

## 📌 HTML Image Tag (`<img>`)

The Image Tag is used to display images on a webpage.

### Syntax

```html
<img src="image.jpg" alt="Description of Image">
```

### Example

```html
<img src="profile.jpg" alt="Profile Photo" height="250" width="250">
```

### Common Attributes

| Attribute | Description                                        |
| --------- | -------------------------------------------------- |
| `src`     | Specifies the path of the image                    |
| `alt`     | Displays alternative text if the image cannot load |
| `height`  | Sets the image height                              |
| `width`   | Sets the image width                               |

### Purpose

* Adds visual content to webpages.
  
* Improves user experience.
  
* Makes websites more attractive and informative.

---

## 📌 HTML Comments

Comments are used to add notes inside HTML code. They are ignored by the browser and are not displayed on the webpage.

### Syntax

```html
<!-- This is an HTML comment -->
```

### Example

```html
<!-- Main Heading -->
<h1>Welcome to My Website</h1>

<!-- Profile Image -->
<img src="profile.jpg" alt="Profile Photo">
```

### Purpose

* Improves code readability.
  
* Helps developers understand code sections.
  
* Makes maintenance easier.
  
* Useful for debugging and documentation.

---

## 💻 Complete Example

```html
<!DOCTYPE html>
<html>
<head>
    <title>Image Tag and Comments</title>
</head>
<body>

    <!-- Website Heading -->
    <h1>My Profile</h1>

    <!-- Profile Image -->
    <img src="profile.jpg"
         alt="Profile Photo"
         height="250"
         width="250">

    <!-- Description -->
    <p>Hello! Welcome to my webpage.</p>

</body>
</html>
```
