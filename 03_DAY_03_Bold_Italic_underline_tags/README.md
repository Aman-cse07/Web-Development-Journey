# HTML Text Formatting Tags (Bold, Italic & Underline)

## 📖 Introduction

This repository demonstrates the use of HTML text formatting tags. These tags help make webpage content more attractive, readable, and meaningful by emphasizing important text.

## 🎯 Objectives

* Learn how to make text bold in HTML.
  
* Learn how to italicize text.
  
* Learn how to underline text.
  
* Understand the purpose of text formatting tags.
  
* Build a simple webpage using formatted text.

---

## 📌 Bold Tag (`<b>`)

The `<b>` tag is used to display text in **bold** format.

### Code

```html
<b>This text is bold.</b>
```

### Output

**This text is bold.**

### Purpose

* Highlights important text.
  
* Makes content more noticeable.
  
* Improves readability.

---

## 📌 Italic Tag (`<i>`)

The `<i>` tag is used to display text in *italic* format.

### Code

```html
<i>This text is italic.</i>
```

### Output

*This text is italic.*

### Purpose

* Emphasizes specific words.
  
* Commonly used for titles, quotes, and foreign words.

---

## 📌 Underline Tag (`<u>`)

The `<u>` tag is used to underline text.

### Code

```html
<u>This text is underlined.</u>
```

### Output

<u>This text is underlined.</u>

### Purpose

* Draws attention to important content.
  
* Highlights specific words or phrases.

---

## 💻 Complete Example

```html
<!DOCTYPE html>
<html>
<head>
    <title>Text Formatting Tags</title>
</head>
<body>

    <h1>HTML Text Formatting</h1>

    <b>This text is bold.</b>
    <br><br>

    <i>This text is italic.</i>
    <br><br>

    <u>This text is underlined.</u>

</body>
</html>
```
